# Sudoku 🧩

Free Sudoku game — no ads, no sign-up, mobile-friendly.

## Play

👉 https://geea-develop.github.io/sudoku/

## Features

- 🧩 Valid puzzles with guaranteed unique solutions
- 📊 Three difficulty levels (Easy / Medium / Hard)
- ✅ Real-time error highlighting
- 🎉 Win celebration
- 🔊 Sound effects
- 📳 Haptic feedback on mobile
- 📱 Mobile-first responsive design
- 🚫 No ads, no tracking, no sign-up

## Tech Stack

- Next.js 15 + React 19 + Tailwind CSS + TypeScript
- GitHub Pages + GitHub Actions CI/CD

## Development

```bash
npm install
npm run dev
```
